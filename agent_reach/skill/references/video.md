# Video

This edition supports YouTube.

## YouTube subtitles

```bash
yt-dlp --write-sub --write-auto-sub --skip-download -o "/tmp/%(id)s" "URL"
```

When subtitles are unavailable and a configured transcription provider exists,
follow the Agent Reach/Doctor guidance for audio transcription.

## Search / metadata

Use the retained YouTube route selected by the environment. Verify the video
ID/title before summarizing when similarly named videos exist.

Do not download large media files unless the task actually requires it.
